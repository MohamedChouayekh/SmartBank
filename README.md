# SmartBank – Mobile Banking Application

SmartBank is an academic mobile banking application developed
during my internship at BIAT-IT in Tunisia.

The project simulates banking services through a mobile
application connected to a REST API.

## Key Features

- User authentication with JWT.
- Password hashing using BCrypt.
- Bank account and transaction management.
- Internal transfers with business rule validation.
- Cashback and loyalty rewards management.
- Partner discounts and offers.
- AI-powered virtual assistant using Gemini.
- Partner location using OpenStreetMap.
- Separate client and administrator interfaces.

## Technology Stack

**Mobile:** Flutter, Dart

**Backend:** Java, Spring Boot

**Database:** MySQL

**Security:** JWT, BCrypt

**Integrations:** Google Gemini API, OpenStreetMap

**Tools:** Git, GitHub, Maven

## Architecture

The application follows a client-server architecture:

- Flutter mobile application.
- Spring Boot REST API.
- MySQL relational database.

## Database Design

The backend database model includes 19 JPA entities
covering users, accounts, cards, transactions, rewards,
partners and support requests.

## Testing

The application was tested on a physical Android device
and through Chrome across 22 test scenarios.
